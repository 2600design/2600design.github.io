Lettrine

Lettrine is a wedding platform designed and developed by 2600 Design, bringing 61 wedding website templates, digital invitations and guest management into one place. The challenge was to give every design its own character while making personalisation and RSVPs feel simple.

The idea

A personal beginning.
Every detail together.

A wedding website needs to hold both a couple’s story and the details their guests rely on. Lettrine brings the schedule, venues, travel, photographs and replies together, with a choice of 61 visual directions.

Our work covered the product structure, art direction, interface design and responsive frontend. Couples enter their content once, explore different designs and preview the guest experience before publishing. The shared system carries their words and photographs between designs without starting again.

  • Template art direction
  • Content editing & live previews
  • Responsive wedding websites
  • Guest management & RSVP

Design decisions

Different characters.
One shared experience.

MORROW uses generous space, restrained typography and an editorial arrangement of photographs. PROMENADE takes a more romantic direction, with a storybook Paris setting, calligraphic names and a pink evening sky. Each design has its own composition, image treatment and pace.

Behind those visual differences, the editing and guest journeys stay consistent. Couples personalise, preview and publish; guests find their invitation and reply by household, person and event, with meal choices and dietary notes kept alongside the right reply.

Product scope

61 templates.
A complete wedding journey.

The collection spans botanical, coastal, formal, editorial, minimal and illustrated styles. These are distinct website compositions, each with its own typography, photography, colour palette and visual rhythm, connected by a shared content and editing system.

Design discovery

Browse and filter 61 website templates, explore the detail pages and open live previews before choosing a design.

Live personalisation

Edit names, dates, stories, events, venues and photographs. Changes appear in the preview, with desktop, tablet and mobile views, autosave and design switching.

Wedding information

Bring the programme, travel, accommodation, FAQs, dress code, registry and photo gallery together in one responsive website.

Publishing & sharing

Keep working drafts separate from the published website. Publish, update or unpublish, then share a guest link, household link or QR code.

RSVP & guest management

Import guest lists, organise households and collect replies by person and event. Track attendance, meal choices and dietary notes, with seating tools and catering exports.

Digital invitations

An invitation collection extends the visual experience beyond the website. Selected designs have companion invitations, with editable wedding details and a path back to the guest experience.

Technology & build

Designed as a collection.
Built as a system.

The implementation uses HTML, CSS and vanilla JavaScript modules for the interface, with a Node.js backend. A shared wedding data model separates the couple’s content from the selected design, so the same information can be presented through different templates.

Frontend
HTML, responsive CSS and JavaScript ES modules. Individual template renderers control composition and styling, while a shared editor handles content, preview state and design selection.
Backend & publishing
Node.js 22 with HTTP API routes for projects, media, guests and publishing. Published snapshots are kept separate from editable drafts, so new changes reach guests when the couple republishes.
Data & storage
Versioned wedding data with validation, local browser draft recovery and filesystem persistence in development. SQLite is implemented for local SQL workflows; a PostgreSQL adapter boundary is prepared for production integration.
Images & presentation
Role-based image slots carry the couple’s photographs into each template. Uploaded media is stored by reference, while curated colourways, type pairings and responsive layouts preserve each design’s character.
Testing & quality
Node.js tests cover data, editing, publishing and RSVP logic. Playwright supports browser journey and responsive checks, with axe-core accessibility checks and performance budgets in the QA tooling.

Current stage: Functional prototype, with the website collection, editor, publishing and guest workflows implemented. Live payment, email, domain and production infrastructure integrations remain part of the next stage; the invitation collection is still being refined.
