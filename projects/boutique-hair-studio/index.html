Boutique Hair Studio

A refined website for a boutique salon with a modern, minimal feel.

Salon website design concept

The work covers website design, layout structure, visual direction and mobile optimisation. The homepage and supporting content layouts carry the same typography and spacing system, creating a consistent experience across the website.
